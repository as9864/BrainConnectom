# 논문 해설: BioNIC — 커넥토믹스 원리를 이용한 생물학적 영감 신경망

> 원문: Diya Prasanth, Matthew Tivnan, *"BioNIC: Biologically Inspired Neural Network for
> Image Classification Using Connectomics Principles"*, arXiv:2601.20876 (2026).
>
> 아래 내용은 원문을 그대로 옮긴 번역이 아니라, 논문을 읽고 **제 표현으로 재구성한 해설**입니다.
> 정확한 수치·문장이 필요하면 반드시 [원문 PDF](https://arxiv.org/abs/2601.20876)를 직접 확인하세요.
> (학술 논문 전문을 그대로 다른 언어로 옮기는 것은 원저작물의 번역권을 침해하는 행위라, 전문 번역 대신 이 해설로 대신합니다.)

이 문서를 `docs/papers/`에 넣은 이유는, 이 논문이 지난 대화에서 나온 **"커넥톰을 인코더 구조로 보고 확장하면 더 좋아지는가"**라는 질문에 대해 실제로 실험까지 해본, 이 저장소(`BrainConnectom`)의 연구 방향과 가장 가까운 선행 연구이기 때문입니다.

---

## 1. 한 줄 요약

마우스 1차 시각피질(V1)의 실제 시냅스 연결 지도(MICrONS 커넥톰)를 신경망의 "배선 제약"으로 사용해서 표정 인식(FER-2013) 모델을 만들었더니, **일반적인 CNN과 거의 같은 성능(정확도 약 60%)**이 나왔고, **"진짜 배선 구조"보다 "데이터 증강·정규화 같은 기능적 학습 메커니즘"이 성능에 훨씬 크게 기여**했다는 것을 절제 실험(ablation study)으로 밝혀낸 논문입니다.

---

## 2. 문제의식과 배경

- FER-2013은 사람 표정 사진 7종(행복·중립·슬픔·화남·놀람·역겨움·공포)을 분류하는 유명한 벤치마크인데, 사람이 직접 맞혀도 정확도가 65% 안팎일 정도로 원래 어려운 과제입니다.
- 기존 연구들은 CNN 계열 모델로 이 문제를 풀어왔지만, "생물학적으로 얼마나 그럴듯한 구조인가"는 대체로 신경 쓰지 않았습니다.
- 최근 몇 년 사이 전자현미경 기반 커넥토믹스(FlyWire, FANC, HCP, 그리고 이 논문이 쓴 MICrONS 등)가 페타바이트급 데이터를 쏟아내기 시작하면서, "이 실측 배선도를 신경망 설계에 직접 반영해보자"는 흐름이 생겼고, 저자들은 그 계보(Goulas et al., MouseNet, Lappalainen et al., Elegans-AI, conn2res 등 — 이 저장소의 이전 대화에서 다룬 것과 상당수 겹칩니다)를 이어 마우스 V1 커넥톰으로 이 실험을 했습니다.

## 3. 데이터

**과제 데이터셋 — FER-2013**
- 48×48 흑백 얼굴 사진 35,887장 (학습 28,709 / 테스트 7,178), 7개 감정 클래스
- 클래스 불균형이 심하고, 저해상도라 표정 디테일이 부족하며, 감정 사이 경계가 모호하다는 것 자체가 도전 과제

**구조 데이터 — MICrONS 커넥톰**
- IARPA가 주도한 대형 프로젝트로, 마우스 시각피질 1mm³ 부피를 전자현미경으로 통째로 재구성한 데이터셋 (이 저장소 이전 대화에서 다룬 바로 그 MICrONS입니다)
- 그중에서도 **V1 영역의 세로 기둥(cortical column) 하나**만 골라서 사용 — 뉴런 약 1,000여 개 규모의 부분집합
- CAVE(Connectome Annotation Versioning Engine)라는 공식 API로 뉴런 정보(흥분성/억제성 여부, 세부 세포 타입, 위치)와 시냅스 정보(뉴런 쌍 사이 시냅스 개수·크기)를 받아와서, 이 기둥 안의 "누가 누구와 얼마나 연결돼 있는가"를 완전한 인접행렬로 구성했습니다.

## 4. 모델 구조 — "신경망 배선을 실측 데이터로 마스킹하기"

핵심 아이디어는 단순합니다: **일반적인 완전연결(dense) 레이어의 가중치 행렬에, 실제로 관측된 시냅스가 없는 자리는 0으로 강제로 고정하는 "마스크"를 곱한다**는 것입니다. 즉 학습 가능한 파라미터는 그대로 두되, 존재하지 않는 연결은 절대 학습되지 않도록 원천 차단하는 방식입니다.

전체 파이프라인은 대략 이렇게 흘러갑니다.

```
48×48 흑백 이미지
   │  합성곱 레이어 1 (8개 필터) → 측면 억제(lateral inhibition)
   │  합성곱 레이어 2 (16개 필터) → ReLU
   │  채널/공간 어텐션 (CBAM 방식)
   ▼
생물학적 레이어 A (뉴런 266개, 실제 세포 타입 "4P"에 대응)
   │  ← 레이어 간 연결은 실측 인접행렬로 마스킹
   │  ← 같은 레이어 안의 뉴런끼리도 실측 데이터로 마스킹된 연결 존재(intra-layer)
   │  ← 억제성 뉴런으로부터 많이 입력받을수록 활성을 깎는 "누그러진 억제" 적용
   ▼
생물학적 레이어 B (349개, "23P") → 레이어 C (185개) → 레이어 D (383개)
   ▼
선형 분류기 → 7개 감정 클래스
```

몇 가지 설계 포인트가 흥미롭습니다.

- **레이어 나누기 방식**: 실제 V1은 6개 층(layer 1~6)으로 나뉘는데, 저자들은 이를 정보 흐름 순서에 따라 4개의 "가설적 레이어"(A~D)로 단순화하고, 각 레이어에 속하는 실제 세포 타입들의 뉴런 수를 그대로 그 레이어의 크기로 삼았습니다.
- **합성곱 레이어는 왜 있는가**: 실제 시각 정보는 망막→시상(LGN)을 거치며 "레티노토피(공간 배치를 유지하는 지도)" 형태로 V1에 들어오는데, 이 과정을 합성곱 레이어가 대신 담당하도록 설계했습니다. 즉 "커넥톰 마스킹 레이어" 이전 단계는 통상적인 CNN이고, 그 이후부터가 실측 배선을 반영한 부분입니다.
- **억제성 뉴런 처리**: 실제로 억제성 시냅스를 많이 받는 뉴런일수록 활성이 깎이도록, "들어오는 억제성 연결 수"를 정규화한 값만큼 활성을 낮추는 수식을 적용했습니다.
- **헤비안 가소성 + 항상성**: 표준적인 역전파 학습 위에, "같이 활성화된 뉴런끼리는 연결을 강화한다"는 헤비안 규칙과 "평균 발화율이 목표치에서 벗어나면 되돌린다"는 항상성 규칙을 소량 추가로 얹었습니다.
- 이 밖에도 데이터 증강, 시냅스 잡음(가우시안 노이즈), 층 정규화(LayerNorm), 가중치 감쇠, 라벨 스무딩, 학습률 스케줄러까지 총 12가지 "생물학적으로 그럴듯한" 장치를 하나씩 조합했습니다.

## 5. 실험 방법

- 비교 대상: 위 12가지 장치를 전부 켠 "풀 모델(BioNIC)" vs 생물학적 요소가 전혀 없는 표준 CNN vs 12가지 장치를 하나씩 꺼본 절제 실험 12종 — 총 14개 모델
- 모든 모델은 같은 조건(배치 크기 32, 최대 400 에폭, 조기 종료, Adam 옵티마이저)에서 시드를 3번 바꿔가며 학습해 평균±표준편차로 보고
- 평가지표: 정확도, F1, 혼동행렬, ROC-AUC

## 6. 결과

### 6.1 풀 모델 vs 표준 CNN

| | 표준 CNN | BioNIC(풀 모델) |
|---|---|---|
| 테스트 정확도 | 60.16 ± 0.45% | 59.77 ± 0.27% |
| Macro F1 | 0.5510 | 0.5652 |
| 파라미터 수 | 1,381,223 | 1,536,684 |

**거의 동률**입니다. 다만 클래스별로 보면 흥미로운 차이가 있습니다 — 표준 CNN은 "역겨움" 클래스를 정밀도는 높게(0.88) 맞히지만 재현율은 낮은(0.26) 반면, BioNIC은 재현율이 0.40으로 더 높아지는 대신 정밀도가 0.59로 떨어집니다. 즉 **BioNIC이 소수 클래스를 "더 적극적으로" 예측하는 경향**을 보였고, 그 결과 전체 macro F1은 BioNIC이 살짝 더 높게 나왔습니다.

### 6.2 절제 실험 — 뭘 빼면 얼마나 나빠지는가

가장 핵심적인 결과표입니다. "구조적" 요소(실측 배선 마스크, 층내 연결, 측면 억제, 누그러진 억제)와 "기능적" 요소(데이터 증강, 합성곱, 층 정규화, 라벨 스무딩, 학습률 스케줄러)를 나눠서 봤을 때:

**구조적 제약을 뺐을 때의 정확도 변화**
| 제거한 요소 | 정확도 변화 |
|---|---|
| 실측 배선 마스크 | −1.01% |
| 층내(intra-layer) 연결 | −0.60% |
| 측면 억제(lateral inhibition) | −0.24% |
| 누그러진 억제(graded inhibition) | −0.12% |

**기능적 메커니즘을 뺐을 때의 정확도 변화**
| 제거한 요소 | 정확도 변화 |
|---|---|
| 데이터 증강 | −22.82% |
| 합성곱 레이어 | −12.14% |
| 층 정규화(LayerNorm) | −9.12% |
| 라벨 스무딩 | −2.16% |
| 학습률 스케줄러 | −1.01% |

가장 영향이 컸던 기능적 요소(데이터 증강, −22.82%)가 가장 영향이 컸던 구조적 요소(배선 마스크, −1.01%)보다 **약 23배** 더 큰 영향을 미쳤습니다. 데이터 증강을 완전히 빼면 정확도가 36.95%까지 폭락하고, 학습이 4.4배 더 빨리 조기 종료되는데도 성능은 훨씬 나쁜, 전형적인 과적합 패턴을 보였습니다. 반대로 배선 마스크를 빼면 모델의 표현력(capacity)은 오히려 늘어나는데도 성능은 소폭(1.01%)만 떨어졌습니다.

## 7. 논의 — "구조 vs 기능"

저자들이 가장 강조하는 결론은 이것입니다:

> **실제 배선 구조를 그대로 반영하는 것(structural)보다, 항상성·정규화 같은 생물학적 학습 메커니즘을 반영하는 것(functional)이 성능에 훨씬 더 크게 기여했다.**

다만 구조적 제약이 "쓸모없다"는 뜻은 아니라고 지적합니다 — 배선 마스크를 빼면 파라미터 수는 늘지만 성능 향상은 미미했고, 오히려 "화남"·"공포"처럼 구별하기 어려운 클래스에서는 배선 마스크가 있는 쪽이 더 나은 클래스별 정확도를 보였습니다. 즉 **구조적 제약의 역할은 "정확도를 크게 올리는 것"이 아니라 "적은 파라미터로 과적합 없이 특정 어려운 클래스를 더 잘 구별하게 돕는 것"**에 가깝다는 해석입니다.

## 8. 한계

- V1 안에서도 세로 기둥 하나(뉴런 약 1,000여 개)만 모델링했고, 망막·시상(LGN)이나 편도체·안와전두피질처럼 감정 해석에 실제로 관여하는 상위 뇌 영역은 전혀 포함하지 않았습니다.
- 절제 실험은 요소를 "하나씩만" 뺐기 때문에, 구조적 요소와 기능적 요소가 "함께 작용할 때"의 시너지는 확인하지 못했습니다(저자들도 향후 요인설계(factorial design) 실험이 필요하다고 명시).
- 헤비안 가소성·항상성 등도 실제 생물학적 기전을 수학적으로 단순화한 근사치입니다.

## 9. 결론

풀 모델(BioNIC)이 표준 CNN을 능가하지는 못했지만, 대략 같은 수준의 성능을 실측 배선 제약만으로도 낼 수 있다는 것을 보였고, "AI 설계에 생물학적 구조 제약을 넣는 것이 계산적으로 실현 가능하다"는 걸 증명한 것 자체에 의의를 둡니다.

---

## 10. 이 저장소(BrainConnectom) 연구와의 접점

- **"커넥톰을 인코더로 보고 확장하면 좋아지는가"**라는 질문에 대해, 이 논문은 (확장까지는 아니지만) "고정 크기에서 구조 대 기능을 분리해서 정량적으로 비교"하는 방법론 자체를 보여줍니다. `reservoir_experiment/`, `flyhash_experiment/`에 이 논문처럼 **"구조적 요소 vs 기능적 요소" 절제 실험 축**을 추가하면, 지금 하고 있는 실험들이 훨씬 더 이 논문과 직접 비교 가능한 형태가 됩니다.
- 이 논문이 쓴 **MICrONS 데이터 접근 방법(CAVE client, cortical column 서브셋 추출)**은 `docs/ARCHITECTURE.md`의 확장 포인트 표에 있는 "더 큰/다른 종의 커넥톰으로 교체" 항목과 정확히 같은 절차라, 향후 `reservoir_experiment/connectome.py`에 마우스 데이터를 추가할 때 그대로 참고할 수 있습니다.
- 저자들의 핵심 발견("구조보다 기능이 더 크게 기여")은, 지난 대화에서 제안한 **"스케일링 커브" 실험**의 가설 하나를 뒷받침합니다 — 즉 구조적 이점이 스케일이 커질수록 희석될 수 있다는 우려가 이미 (다른 과제·다른 스케일에서지만) 한 번 관측된 사례라는 뜻입니다. 다만 이 논문은 스케일을 키우는 실험은 하지 않았으므로, "스케일에 따라 이 격차가 어떻게 변하는지"는 여전히 열려 있는 질문입니다.
